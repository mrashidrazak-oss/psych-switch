## Key decision logic to verify (per engine)

1. **Lithium toxicity** — tier = worse of level band (≥1.5 mild,
   ≥2.5 moderate, ≥3.5 severe) vs clinical features; dialysis if
   level ≥4.0, or ≥2.5 with severe clinical/renal failure.
   *Source: Maudsley 15e; EXTRIP/Decker 2015.*
2. **Alcohol withdrawal** — chlordiazepoxide default; lorazepam if
   hepatic/elderly; symptom-triggered inpatient vs fixed outpatient;
   parenteral thiamine + magnesium caution. *NICE CG100 / SIGN 74.*
3. **OST induction** — buprenorphine COWS≥12 gate + precipitated-
   withdrawal warning + low-tolerance dose drop; methadone
   accumulation caution. *UK Orange Book 2017.*
4. **Wernicke / thiamine** — prophylaxis vs treatment regimens;
   glucose-before-thiamine rule; magnesium cofactor. *Maudsley 15e /
   NICE CG100 / RCP.*
5. **Hyponatraemia/SIADH** — band = worse of Na (≥130 mild, ≥125
   moderate, <125 severe) vs symptoms; ≤8–10 mmol/L/24 h correction
   cap; acute-onset hypertonic-saline note. *Maudsley 15e / UK
   hyponatraemia consensus.*
6. **Hyperprolactinaemia** — mIU/L bands; ≥2000 → mandatory
   pituitary MRI / exclude prolactinoma; macroprolactin caveat;
   prolactin-sparing switch. *Maudsley 15e / Endocrine Society.*
7. **Clozapine myocarditis** — baseline + weekly troponin/CRP first
   4 wk; any red (troponin >2×ULN / CRP >100 / HF) = STOP; ≥2 amber
   = suspected; 1 amber = urgent review. *Maudsley 15e / Ronaldson.*
8. **Valproate PPP** — verdict from childbearing potential,
   pregnancy, bipolar (stricter), alternatives, contraception,
   signed Risk Acknowledgement Form, annual specialist review;
   ~10% malformation / ~30–40% neurodevelopmental. *Maudsley 15e /
   MHRA.*
9. **Olanzapine LAI PDSS** — ≥3 h observation, no driving,
   accompanied transport; any feature → suspected PDSS emergency;
   no antidote. *Maudsley 15e / pamoate RMP.*
10. **Opioid overdose** — community take-home vs supervised titrated
    naloxone; re-narcotisation safety net; long-acting/methadone →
    infusion + admit. *Maudsley 15e / Orange Book 2017.*
11. **Pre-stimulant cardiac** — 6 red flags → cardiology clearance
    first vs proceed with baseline HR/BP/ht/wt monitoring.
    *Maudsley 15e / NICE NG87.*
12. **High-dose antipsychotic** — cumulative %-of-max across 12
    agents; >100% = HDAT safeguards (rationale, ECG/QTc, obs,
    consent, reduction plan). *Maudsley 15e / RCPsych HDAT.*
13. **Buprenorphine micro-dosing** — Bernese standard ~7-day vs
    rapid ~4-day; full agonist continued to stop day; methadone/
    fentanyl cautions. *Maudsley 15e / published Bernese protocols.*
14. **Acute pain on OST** — continue maintenance + treat pain
    additionally; methadone QT/sedation, buprenorphine high-affinity
    (specialist), naltrexone blockade (stop oral ~72 h). *Maudsley
    15e / Orange Book 2017.*
15. **Antipsychotic in Parkinsonism/LBD** — non-drug first;
    quetiapine/clozapine/pimavanserin preferred; severe (fatal)
    Lewy-body neuroleptic sensitivity; stroke/mortality + review.
    *Maudsley 15e / NICE.*
16. **Serotonergic-opioid** — opioid tier (strong: pethidine/
    tramadol/tapentadol; weak; none) × agent (MAOI/SSRI/…) →
    contraindicated (pethidine+MAOI) / high / caution / low;
    Hunter criteria. *Maudsley 15e.*
17. **Steroid psychiatric** — scenario-driven; dose-related
    (>~40 mg/day prednisolone-equiv); no routine prophylaxis;
    reduce steroid with prescriber; never stop abruptly. *Maudsley
    15e.*
18. **Weight-gain ladder** — %-gain bands; ≥7% → metformin + switch
    consideration; ≥15% specialist + GLP-1/orlistat; highest-risk
    olanzapine/clozapine. *Maudsley 15e.*
19. **Clozapine GI hypomotility** — red (distension+pain/vomiting/
    no flatus/absent bowel sounds) = surgical emergency; amber =
    escalate laxatives; default prophylaxis. *Maudsley 15e.*
20. **Antidepressant sexual dysfunction** — assess → conservative →
    switch (if remission) → adjunct (bupropion/PDE5). *Maudsley 15e.*
21. **Lamotrigine titration** — alone vs +valproate (halved) vs
    +inducer (faster); benign rash = withhold/review; mucosal/
    blistering/systemic = serious-rash emergency, no rechallenge;
    >5-day miss = re-titrate. *Maudsley 15e / BNF.*
22. **Tardive dyskinesia** — confirm/remove anticholinergics →
    modify antipsychotic (clozapine/quetiapine) → VMAT-2 inhibitor →
    refractory specialist; do-not-mask caution. *Maudsley 15e.*
23. **NMS rechallenge** — gated on full + biochemical recovery and
    ≥~2-wk delay; different lower-potency class, slow oral, no
    lithium, CK/temp monitoring. *Maudsley 15e.*
24. **Perioperative psychotropics** — default continue; lithium hold
    + fluids/NSAID caution; MAOI specialist (avoid pethidine);
    clozapine continuity + re-titration; SSRI bleeding; benzo/
    valproate withdrawal-seizure; stimulant day-of omission.
    *Maudsley 15e.*
25. **Febrile-clozapine differential** — weights features to benign
    vs myocarditis vs agranulocytosis/sepsis vs NMS vs serotonin;
    red = withhold + emergency; sore throat = urgent FBC; none =
    still full work-up. *Maudsley 15e.*
